# 🏠 Airbnb SQL Analysis

## 📌 Project Overview

This project focuses on analyzing Airbnb listing and booking data using SQL. 
The project covers different SQL concepts to extract meaningful information 
from the dataset and perform data analysis.

## 🎯 Objectives

- Analyze Airbnb listing and booking data
- Find pricing and availability information
- Analyze neighbourhoods and room types
- Identify hosts and listing information
- Use SQL queries to answer business-related questions

## 🗂️ Dataset

The project uses two tables:

- **Listings** – Contains listing, host, neighbourhood, and room type information.
- **Booking Details** – Contains price, minimum nights, availability, reviews, and related booking information.

## 🛠️ SQL Concepts Used

- SELECT
- DISTINCT
- WHERE
- BETWEEN
- IN
- Aggregate Functions
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- JOIN
- Subqueries
- EXISTS

## 🔍 Analysis Performed

The project includes queries for:

- Total number of listings
- Unique hosts and neighbourhoods
- Minimum, maximum, and average prices
- Room type analysis
- Neighbourhood-wise price analysis
- Availability analysis
- Review analysis
- Host-wise price analysis
- Subquery-based analysis
